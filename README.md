# VisualMind

VisualMind is a human-centered Creative Intelligence architecture for developing effective Digital Assets. It establishes structured knowledge, perception-based evaluation and a confirmed decision process before generation.

## Current status

**Foundation v1.0 — Completed**  
**Design Disciplines — In progress**

- `FOUNDATION.md` — Foundation declaration and stable knowledge level.

- `GESTALT.md` — Source of truth for automatic visual organization.

The permanent project principles are defined in `VISUALMIND_PRINCIPLES.md`.

Foundation-specific applications include Knowledge Before Intelligence and Human-Centered Reasoning, as defined in `FOUNDATION.md`.

This repository stores the VisualMind architecture, methodology, knowledge standards and associated project materials. The documents define the current project position and should be changed through deliberate architectural review.
