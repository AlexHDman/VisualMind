# Creative Specification

## Purpose

Creative Specification определяет структурированную профессиональную концепцию рекламной коммуникации.

Документ фиксирует минимальный набор сведений, необходимый Production Engine для подготовки конечного продукта.

## Required Sections

### Project Goal

Фиксирует целевой результат коммуникации.

### Audience

Определяет целевую аудиторию и значимый контекст её восприятия.

### Core Message

Формулирует главное сообщение коммуникации.

### Communication Strategy

Определяет способ донесения сообщения до аудитории.

### Emotional Direction

Определяет желаемое эмоциональное восприятие коммуникации.

### Psychological Factors

Фиксирует психологические барьеры и факторы доверия.

### Visual Strategy

Определяет роль визуальных средств в передаче сообщения.

### Information Hierarchy

Устанавливает порядок восприятия ключевых элементов коммуникации.

### Readability

Фиксирует требования к понятности и лёгкости восприятия.

### Cognitive Load

Определяет допустимый объём усилий для понимания сообщения.

### Call To Action

Формулирует желаемое действие аудитории.

### Constraints

Фиксирует ограничения, обязательные для подготовки конечного продукта.

### Success Criteria

Определяет признаки соответствия конечного продукта цели коммуникации.

## Result

Creative Specification является обязательным входом Production Engine.

Она передаёт цельную концепцию коммуникации без описания способа её реализации.
