# Engine Principles

## Назначение

Единые правила проектирования всех Engine системы.

## Принципы

### 1. Одна ответственность

Один Engine отвечает за одну определённую область результата.

### 2. Контекст как вход

Engine получает Creative Context как входные данные.

### 3. Отсутствие окончательного выбора

Engine не принимает окончательное решение самостоятельно.

### 4. Структурированный результат

Engine возвращает структурированный результат.

### 5. Независимость Engine

Engine не зависит от других Engine напрямую.

### 6. Заменяемость

Engine может быть заменён без изменения Core.

### 7. Сокрытие реализации

Core ничего не знает о внутренней реализации Engine.

### 8. Соответствие контексту

Engine учитывает цель, ограничения и критерии успеха Creative Context.

### 9. Определённость границ

Engine действует только в пределах своей ответственности и входных данных.

### 10. Проверяемость результата

Результат Engine допускает проверку по критериям успеха.

## Схема

Creative Context
        ↓
Decision Model
        ↓
Engine
        ↓
Structured Result
