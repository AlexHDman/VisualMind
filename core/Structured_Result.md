# Structured Result

## Назначение

Единый контракт обмена результатами между Engine и остальной системой.

Контракт определяет минимальные свойства результата без привязки к его реализации.

Он не определяет способ представления или хранения результата.

## Обязательные свойства результата

### Source

Указывает происхождение результата.

### Purpose

Фиксирует назначение результата.

### Content

Содержит основной смысловой результат.

### Confidence

Отражает степень обоснованности результата.

### Constraints

Фиксирует ограничения, относящиеся к результату.

### Metadata

Содержит сведения, необходимые для понимания и использования результата.

Все свойства формируют целостное описание результата для его дальнейшего использования.

## Требования

Результат должен быть:

- структурированным;

- расширяемым;

- независимым от реализации;

- пригодным для передачи между Engine;

- пригодным для оценки;

- пригодным для сохранения.
