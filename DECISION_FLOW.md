# DECISION FLOW

## Purpose

`DECISION_FLOW.md` устанавливает процесс совместного принятия творческого решения между пользователем и VisualMind Studio до запуска генерации.

VisualMind сначала формирует и подтверждает решение вместе с пользователем, а затем выполняет генерацию. Документ фиксирует этот порядок как архитектурный контракт Studio.

## Decision Flow

```text
User Request
        ↓
Research
        ↓
Creative Analysis
        ↓
Dynamic User Configuration
        ↓
Creative Summary
        ↓
User Confirmation
        ↓
Generation
        ↓
Evaluation
```

### User Request

Пользователь формулирует задачу, цель или исходную потребность. Запрос является начальной точкой для уточнения, а не непосредственной командой на генерацию.

### Research

VisualMind собирает и рассматривает доступный контекст задачи: исходные материалы, цель, аудиторию, ограничения и релевантные знания. Объём исследования определяется реальной необходимостью для решения.

### Creative Analysis

VisualMind анализирует задачу и формирует обоснованное направление решения. Анализ связывает запрос с целью коммуникации, контекстом и ожидаемым результатом.

### Dynamic User Configuration

Пользователю предлагаются только параметры, релевантные текущему решению. Пользователь уточняет направление, выбирает применимые варианты и дополняет недостающий контекст.

### Creative Summary

VisualMind формирует краткое общее описание будущего результата на основе запроса, анализа и уточнений пользователя. Summary делает предлагаемое решение понятным до генерации.

### User Confirmation

Пользователь подтверждает Creative Summary или возвращает решение на уточнение. Подтверждение фиксирует общее понимание направления перед генерацией.

### Generation

После подтверждения VisualMind выполняет генерацию в соответствии с согласованным Creative Summary и утверждённым контекстом.

### Evaluation

Результат оценивается относительно подтверждённого решения и исходной задачи. При необходимости следующий цикл начинается с уточнения, а не с неограниченной повторной генерации.

## Decision Rules

- Генерация не начинается сразу после запроса.
- AI сначала анализирует задачу.
- Пользователю предлагаются только релевантные параметры.
- Пользователь уточняет направление решения.
- Перед генерацией создаётся Creative Summary.
- Генерация выполняется только после подтверждения пользователем.

## Creative Summary

Creative Summary — человеко-понятное описание будущего результата. Он фиксирует согласованное направление решения, существенный контекст и ожидаемый результат.

Creative Summary не является промптом. Он служит подтверждением общего понимания задачи между пользователем и VisualMind до запуска генерации.

## Architectural Principles

This contract applies the permanent principles **Professional Reasoning Before Generation** and **User Confirmation Before Production** defined in `VISUALMIND_PRINCIPLES.md`.

The Decision Flow above defines their operational sequence for VisualMind Studio.
