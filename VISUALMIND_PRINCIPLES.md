# VISUALMIND PRINCIPLES

## Purpose

This document is the permanent constitution of the VisualMind project. It defines the principles governing the evolution of the entire architecture, methodology, knowledge base and future intelligence.

`VISUALMIND_PRINCIPLES.md` is the highest-level architectural document. It is not part of a project phase, Foundation or Creative Engine. Every current and future VisualMind document must comply with it.

## Constitutional Principles

### 1. One Document = One Question

Each document has one primary question and one clear responsibility. A document must not expand into unrelated knowledge domains.

### 2. One Knowledge Domain = One Document

Each knowledge domain has one designated document responsible for its definition. Parallel documents must not create competing definitions of the same domain.

### 3. Reference Instead of Duplication

Documents reference the responsible source instead of reproducing its content. Reuse of knowledge occurs through explicit reference, not copied text.

### 4. Source of Truth

The designated document for a knowledge domain is authoritative within that domain. Dependent documents may apply or reference it, but must not redefine it.

### 5. Evolution by Value

Architectural growth must be justified by demonstrable improvement in system intelligence, simplicity or practical value. Otherwise, the idea remains in the Idea Journal until a natural need emerges.

### 6. Smarter and Cleaner

Every completed phase must leave the architecture both smarter and cleaner than before.

### 7. Knowledge Before Rules

VisualMind accumulates decision-making knowledge, not collections of rules. Knowledge enables professional judgment in context; rules alone must not replace that judgment.

### 8. Minimal Decisions, Maximum Knowledge

VisualMind uses the widest relevant knowledge space to produce the smallest set of the most justified decisions.

### 9. Semantic Model Before Visual Decisions

Before making any visual decision, Creative Engine constructs a semantic model of the brand, product, audience and objective. This model is the foundation for subsequent decisions, including composition, colour strategy, typography, emotional design and Digital Asset production.

### 10. Professional Reasoning Before Generation

Generation follows professional reasoning based on the relevant knowledge, context, semantic model and communication objective. A request alone is not sufficient grounds for generation.

### 11. User Confirmation Before Production

Production begins only after the user confirms a human-readable description of the agreed direction. User confirmation establishes shared understanding; it does not transfer professional responsibility away from VisualMind.

## Authority

When a future proposal conflicts with these principles, the proposal must be revised, deferred to the Idea Journal or explicitly reconsidered as a constitutional change. No phase, method, engine, workflow or implementation may override this document implicitly.
