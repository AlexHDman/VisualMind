# Project Orchestrator

## Назначение

Project Orchestrator координирует прохождение проекта через Engine.

Он связывает Creative Context, Decision Model и Structured Results в единое движение проекта к цели.

## Получает

### Creative Context

Контекст проекта, определяющий цель, ограничения и критерии успеха.

### Decision Model

Модель, определяющую текущую логику принятия решения.

### Structured Results

Результаты, сформированные Engine в ходе проекта.

## Отвечает

### Следующий этап

Определяет следующий этап проекта в соответствии с его текущим состоянием.

### Категория Engine

Выбирает необходимую категорию Engine для следующего этапа.

### Передача результата

Передаёт Structured Result следующему Engine.

### Завершение проекта

Завершает проект после достижения его цели.

## Не отвечает

### Генерация контента

Не отвечает за генерацию содержания результата.

### Исследование

Не отвечает за получение и исследование информации.

### Оценка

Не отвечает за проверку, сравнение и оценку результатов.

### Творческие решения

Не отвечает за принятие творческих решений.

## Схема

User
    ↓
Creative Context
    ↓
Decision Model
    ↓
Project Orchestrator
    ↓
Engine
    ↓
Structured Result
